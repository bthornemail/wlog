Repository Principles

  • `src/` contains active product code only.
  • `apps/` contains the active page bootstraps used by root HTML shells.
  • `legacy/` and `vendor/` are preserved but not part of the main product path.
  • `index.org` is the catalog spine for concepts, layers, and active inventory.
