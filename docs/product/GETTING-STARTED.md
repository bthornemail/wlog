# Getting Started

## Install

```bash
npm install
```

## Validate the Repo

```bash
npm run catalog
npm run check:repo
npm run typecheck
```

## Run the App

```bash
npm run dev
```

Open the active shells from the Vite server:

- `/`
- `/viewer.html`
- `/scene.html`
- `/compose.html`
- `/aztec-slide-rule.html`
- `/quartet-reconciliation-demo.html`

## Build

```bash
npm run build
```
